Claude plays Factorio.

Full structured game state in — entities, inventories, recipes, research — Python code out. No pixels, no vision model, just Claude driving a real Factorio server through its own Lua/RCON API.

View on GitHub Run it

How it works

Each turn, Claude receives the stdout/stderr from its last action as an observation and returns a Python snippet. agent.py runs that snippet through FLE's gym environment against the Lua/RCON bridge inside a headless Factorio server container, and the result becomes the next observation.

Runs on a local model by default — no API key required.
