An LLM plays Factorio, for real.

Real game state in, a deterministic skill picked out. No pixels, no vision model, just an LLM driving a live Factorio server through its own Lua/RCON API.

How it works

Every turn, the model sees real game state and picks a skill from a fixed library (harvest, mine, smelt, craft, auto_feed, belt, ...) — never raw code. Each skill verifies its own success against live game state before returning. FLE's gym environment runs it against a real headless Factorio server. No hardcoded plan. It reads what's real and decides what's next.

Starts from a genuinely vanilla game, no free starting warehouse. Runs on a local model by default. No API key, no cloud bill.

FLE's own benchmark puts Claude ahead of GPT, Gemini, and Grok at this, and still finds every frontier model loses track of what it's built and falls back on manual crafting instead of real automation. That's the gap this project is trying to close.
